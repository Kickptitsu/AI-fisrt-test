# Как запустить

Нужен Python 3.10 или новее. Устанавливать ничего не нужно — только стандартная библиотека.

Из папки проекта:

```
python report.py --date 2026-11-10
```

Дату можно писать и как `10.11.2026`. Дата включительно.

Сохранить отчёт ещё и в CSV для Excel (три файла: работы, итоги по договорам, платежи):

```
python report.py --date 2026-11-10 --csv out
```

Другая папка с данными: `--data путь/к/папке` (по умолчанию `data/` рядом со скриптом).

Тесты:

```
python -m unittest discover -s tests -v
```

## Что где

- `report.py` — CLI.
- `advance/loader.py` — чтение CSV и проверка данных.
- `advance/state.py` — состояние работ и платежей на дату.
- `advance/allocate.py` — разнесение выплат по работам (правило — в `DECISIONS.md`).
- `advance/render.py` — вывод в консоль и CSV.
- `DECISIONS.md` — принятые решения; `NOTE_FOR_ACCOUNTANT.md` — записка бухгалтеру.
